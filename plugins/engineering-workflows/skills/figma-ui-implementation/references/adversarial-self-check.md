# Implementation self-check

Before independent review, answer with evidence:

- What was inferred rather than observed or explicitly required?
- Which visible differences remain at every authoritative viewport and state?
- Does any control appear actionable without completing its promised behavior?
- Which applicable data, interaction, form, content, responsive, or accessibility states lack implementation or tests?
- Are copy, fonts, icons, images, and SVGs authoritative and exact?
- Do semantics and keyboard behavior work without pointer input or visual styling?
- Does the UI survive long content, zoom and reflow, forced colors, reduced motion, slow requests, empty data, malformed data, offline mode, failures, and rapid input where applicable?
- Can stale requests, hydration, subscriptions, or unstable keys produce inconsistent UI?
- Did a dependency, generated artifact, broad format, or unrelated edit enter the diff?
- Were every reported test, screenshot, audit, and measurement run against the final code state?

Return any unresolved required issue to implementation. Do not demote it to a casual limitation to finish.
